## Markdown

正文就是 Markdown：`#` 标题、`-` 列表、`**加粗**`、`` `代码` ``、表格、代码块都行。

- **Ctrl+B / Ctrl+I**：加粗 / 斜体；选中文字按 **Ctrl+K** 加链接。
- 列表里按 Enter 自动续下一项，空项再按一次结束；**Tab / Shift+Tab** 调缩进。
- `- [ ] 任务` 是任务框，预览里能直接勾。

## 双链

- 写 `[[笔记标题]]` 就链到那篇；输入 `[[` 会弹出补全，↑ ↓ 选、Enter 确认。
- 链到还不存在的标题时显示成淡色，点它就新建这篇。
- 右栏「反查链接」能看到谁链到了这篇。

## 标签

- 正文里写 `#标签`，左栏标签云里就能按它筛选。
