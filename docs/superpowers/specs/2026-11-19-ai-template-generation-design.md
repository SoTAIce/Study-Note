# AI 生成模板 设计方案

日期：2026-11-19
状态：**已批准（2026-11-19）**，已完成（见第九节实现记录）
对应条目：tpl-003（`feature_list.json`）

## 一、要解决的问题

现在模板只能手写：小节标题、每节提示一条条填。而「复制成提示词」的文字是按模板自动拼的，改不了。

用户希望让 AI 帮忙：

1. 从几篇写得好的笔记里归纳出共同结构，变成模板；
2. 或者只写一句「我要一个论文阅读笔记模板」，让 AI 设计；
3. AI 同时写好每节提示，以及这个模板专属的、给外部 AI 用的提示词。

## 二、已确定的需求（2026-11-19 问答）

| 问题 | 结论 |
|---|---|
| AI 根据什么生成 | 两种都要：选 1～5 篇笔记归纳；或一句话描述 |
| 「提示词」指什么 | 两种都要：每节的提示（写进 `<!-- -->` 的那句）+ 模板专属的「复制给外部 AI 的提示词」 |

## 三、数据：模板多一个可选字段 `prompt`

```json
{
  "name": "论文阅读",
  "sections": [{ "title": "问题", "hint": "论文要解决什么" }],
  "prompt": "请用中文写；方法一节要画出数据流；结论一节区分作者声称的和实验证明的。"
}
```

- `prompt` 是这个模板的**额外要求**，可以为空，最长 2000 字，不能有控制字符。
- 不经过 AI 也能用：面板里手写或修改都行。
- 旧的 `templates.json` 没有这个字段，照常读。

**复制成提示词时怎么用它**：结构和固定要求仍由应用来拼，`prompt` 插在「要求」后面：

```text
请就「looprun 主循环」写一篇笔记，严格按下面的结构输出：

## 背景
（为什么做、要解决什么问题）
…

要求：
- 只输出 Markdown 正文，从第一个「## 背景」开始，不要开场白、不要结尾的客套话；
- 小节标题、顺序和级别都不要改，不要加别的 ## 小节（小节里可以用 ### 细分）；
- 某个小节没有可写的内容就只写「待补」，不要编造。

这个模板的额外要求：
请用中文写；方法一节要画出数据流；……
```

为什么不让 `prompt` 整段替换：小节结构和「只输出 Markdown、没有写待补」这几条，是 tpl-002「按模板规整」能正确处理回答的前提。这几条固定由应用写，AI 只负责补充这个模板特有的要求，不会把这些前提弄丢。

## 四、界面

模板面板左栏「新建模板」旁边加「让 AI 生成」，打开一个弹层，有两个页签：

**从笔记归纳**
- 搜索框选笔记，最多 5 篇，选中的显示成一排小标签，可以去掉。
- 可选一行「补充说明」，比如「偏重踩坑」。

**一句话描述**
- 文本框：「想要什么样的笔记模板？」，例如「论文阅读笔记，要能记方法和实验」。

点「生成」后：
- 显示「AI 正在整理…」，可以取消。
- 生成结果出现在下方的**预览**里，和面板的编辑区长得一样：模板名、小节（标题 + 提示）、专属提示词，都可以直接改。
- 预览下面显示骨架和提示词的样子。
- 「加入模板列表」：放进左边列表，标成「没保存」，和手工新建的一样，点面板的「保存」才写进 `templates.json`。
- 「重新生成」「放弃」。

另外，现有模板的编辑区里也加两样：
- 「专属提示词」文本框；
- 「让 AI 改写提示词」小按钮：按当前小节重写这一段，结果放进文本框，你确认后再保存。

## 五、接口

| 接口 | 说明 |
|---|---|
| `POST /api/ai/template` | `{ from: "notes", ids: string[], note?: string }` 或 `{ from: "describe", description: string }` → `{ template: { name, sections, prompt } }`。**不写盘**。 |
| `GET/PUT /api/templates` | 模板多 `prompt` 字段，校验长度和控制字符 |

服务端做的事：

1. **从笔记归纳**：
   - 读选中笔记的正文，去掉文件头和提示注释；
   - 每篇最多取 6000 字，总共最多 20000 字，超出的截断并告诉模型「已截断」。
2. **请模型只回 JSON**：`{"name": "...", "sections": [{"title": "...", "hint": "..."}], "prompt": "..."}`。
   - 系统提示要求：小节 3～8 个；标题简短、不带编号；提示一句话；`prompt` 只写额外要求，不重复结构。
3. **校验**：用现有的 `validateTemplate`，再加上 `prompt` 长度检查。
   - 模型回了坏 JSON 或校验不过：返回 422 和原因，不会生成半截模板；
   - 模板名和已有的重复：自动加「 2」。
4. 用的是 AI 设置里配置的服务商和模型，和右栏 AI 动作同一套；没配置时提示先去设置。

## 六、约束

- AI 只产出模板，不改任何笔记。即便如此，也要先看预览，确认后才进列表，保存后才落盘。
- 选中笔记的正文会发给你配置的 AI 服务商，和现有 AI 功能一样；弹层里写明这一点。
- 不新增依赖，颜色只用 token，浅色和深色都要检查。

## 七、测试

- **单元测试**：
  - 带 `prompt` 的模板校验；
  - 提示词拼接：有额外要求和没有两种情况；
  - 模型回复的 JSON 解析：代码块包着、前后有废话、坏 JSON、多余字段。
- **接口测试**（假模型）：
  - 归纳和描述两种方式；
  - 笔记截断；
  - 坏 JSON 返回 422；
  - 重名自动改名；
  - 没配置 AI 时给出提示；
  - 全程不写盘。
- **E2E**：
  - 面板里「让 AI 生成」走描述方式，预览里改一下模板名，加入列表，保存；
  - 新建页复制提示词，能看到「这个模板的额外要求」。

## 八、风险

- **小模型回 JSON 不稳**：解析时容忍外面包着的代码块和多余文字；还是不行就报错，可以重试或换模型。
- **归纳结果太贴某一篇**：选多几篇，或写一句补充说明。预览里也能直接改。

## 九、实现记录（2026-11-19 完成）

按方案做完，以下几处是方案没写细、实现时定下的：

- **「让 AI 改写提示词」也走同一个接口**：方案第五节只列了「归纳」「描述」两种请求，第四节又要求现有模板能让 AI 改写提示词。实现成同一个 `POST /api/ai/template` 的第三种请求 `{ from: "prompt", template }`，只回新的 `prompt`，小节和名字不动，同样不写盘。
- **发给模型的笔记正文去掉提示注释**：模板骨架里的 `<!-- 提示 -->` 不发，免得模型把旧模板的提示照抄成新模板。
- **截断告诉人**：接口多返回 `truncated`（被截断的笔记标题），弹层里提示「《X》太长，只发了前面一部分」。
- **重名**：服务端按已保存的模板加「 2」；面板里还没保存的新模板也算，同名时「加入模板列表」是灰的并提示换名。
- **预览**：生成弹层里骨架和提示词并排显示；模板面板的预览改成两个页签「新建时预填 / 复制成提示词」，改写提示词后自动切到提示词页签。
- **专属提示词的校验**：最长 2000 字；换行和 Tab 可以，其它控制字符不行；首尾空白去掉，空的不写进 `templates.json`（旧文件、旧模板照常读）。

接口：`POST /api/ai/template` → `{ template, truncated, callId }`，不写盘。错误：400（参数不对：没选笔记、超过 5 篇、描述为空或超过 500 字、补充说明超过 200 字）、404（笔记不存在）、422（模型的回复不是合格的模板，什么都没保存）、502（模型没回）、503（AI 未配置）。

验证：见 `feature_list.json` tpl-003 的 evidence 与 `docs/测试文档-2026-11.md` 第十四节。
