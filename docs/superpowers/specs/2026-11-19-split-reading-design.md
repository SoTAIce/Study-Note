# 分屏阅读 设计方案

日期：2026-11-19
状态：**草案，等用户批准**
对应条目：read-002（`feature_list.json`）

## 一、要解决的问题

读一篇笔记时经常要对照另一篇：左边是资料、右边是自己的总结，或者左边是旧方案、右边是新方案。现在只能来回切换。

用户选的是：**两篇笔记左右并排，两边都用阅览模式排版**。

## 二、长什么样

```
┌───────────────────────── 顶栏：行宽 · 字号 · 导出 · 编辑 ─────────────────────────┐
│ 《左边这篇》 目录▾                        ┃ 《右边这篇》 目录▾  ⇄  ×              │
│                                         ┃                                      │
│   阅览排版的正文，自己滚动               ┃   阅览排版的正文，自己滚动             │
│                                         ┃                                      │
└─────────────────────────────────────────┸──────────────────────────────────────┘
                                   拖动中间这条线调左右比例
```

- **进入分屏**：在阅览模式顶栏点「分屏」，弹出和 Ctrl+K 一样的搜索框，选一篇放到右边。
  - 搜索框打开时，最前面列出「上次在右边看的那篇」，方便回到上次的对照。
- **另一种打开方式**：阅览模式里按住 Ctrl（Mac 上是 ⌘）点 [[双链]]，链接指向的那篇在另一栏打开。不按 Ctrl 时和现在一样，在当前栏跳过去。
- **每栏各自的标题条**：
  - 标题；
  - 「目录」：点开是浮层，分屏时每栏太窄，不再常驻左侧；
  - 右栏多两个按钮：⇄ 左右交换、× 关闭右栏回到单篇。
- **中间分隔条**：可以拖动调比例，范围 30%～70%，比例记在本机。双击分隔条恢复各一半。

## 三、行为

- **两边都是阅览排版**：
  - 字号、行宽档位两栏共用顶栏那一套；
  - 版心按每栏自己的宽度算，沿用 read-003 的「自动」规则，所以一栏一半屏宽时字号不会被放大。
- **各自滚动，各自记住读到的位置**：沿用现在按笔记记位置的办法。
- **当前栏**：最后点过或滚过的那一栏，标题条高亮。
  - ← / →、[ / ] 翻篇作用于当前栏，按中间列表的顺序；
  - 顶栏「导出 PDF」导出当前栏那篇；
  - 按 E 或「编辑」打开当前栏那篇的编辑页。
- **Esc**：退出阅览模式，和现在一样回到编辑页（打开的是左栏那篇）。
- **外部修改**：
  - 右栏那篇在别处改了，自动刷新；
  - 被删了，右栏关闭，并提示「《X》已被删除」。
- **窗口太窄**（不到 900px）：「分屏」按钮变灰，悬停时提示「窗口太窄，放不下两栏」。已经在分屏时把窗口缩窄，就只显示当前栏，右上角提示还有另一栏，加宽窗口后恢复。
- **同一篇两边都开**：允许（长文前后对照），两栏位置各自独立。

## 四、实现思路

- 把 `ReadingMode` 里的单栏部分抽成 `ReadingPane`：
  - 目录、滚动、读到的位置、版心计算、正文渲染；
  - 输入是一篇笔记和共用的排版设置。
- `ReadingMode` 只管顶栏、一栏或两栏的布局、分隔条、当前栏、快捷键。
- 右栏的笔记用 `GET /api/notes/:id` 读，外部修改走现有的推送通道（`/api/events`）。
- **不改后端，不加依赖**。分隔条用指针事件自己实现，键盘也能调：焦点放在分隔条上按 ← / →。
- 本机记住的东西都放 localStorage，读写失败时用默认值：
  - 分屏比例；
  - 上次右栏的笔记 id。

## 五、不在这次范围

- 连读页面里分屏：连读本身就是一整本。
- 三栏以上。
- 两栏同步滚动：两篇内容不同，同步没有意义。

## 六、测试

- **单元测试**：
  - 分隔比例的夹紧和读写；
  - 当前栏切换；
  - 翻篇作用到哪一栏；
  - 窄窗口时是否允许分屏。
- **E2E**：
  - 阅览模式点「分屏」选一篇，两栏都显示，各自滚动互不影响；
  - Ctrl+点双链在另一栏打开；
  - 拖分隔条后比例生效，刷新后还在；
  - ⇄ 交换、× 关闭；
  - 当前栏翻篇；
  - 外部改右栏那篇后自动刷新；
  - 窄窗口时按钮变灰；
  - 浅色和深色各截一张图。
