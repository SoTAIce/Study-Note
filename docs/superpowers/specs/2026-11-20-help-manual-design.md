# 内置使用手册 + 速查表 设计方案

日期：2026-11-20
状态：**草案，等用户批准**
对应条目：help-001（`feature_list.json`）

## 一、要解决的问题

功能越来越多（双链、子项目、连读、简卡、模板、规整、AI 生成模板、分屏、导入……），很多只能靠记忆或翻测试文档才知道怎么用：

- 快捷键和特殊语法（`[!card]`、` :: `、`![[图|300]]`）没有地方集中看；
- 没有可以当场动手试的例子。

## 二、已确定的需求（2026-11-20 问答）

| 问题 | 结论 |
|---|---|
| 手册的形式 | **两种都要**：帮助里有只读的手册；另外可以一键生成练习用的笔记 |
| 覆盖范围 | 写笔记基础；模板与 AI；复习与备份（「阅读与导出」这次不单独成章，相关快捷键仍在速查表里） |
| 速查表入口 | 按 `?`（不在输入框里时）和左栏底部的「帮助」按钮；Ctrl+K 输入「快捷键」「帮助」也能找到 |

## 三、内容只有一份

手册正文是仓库里的一组 Markdown 文件：`manual/01-xxx.md`、`manual/02-xxx.md`……

- 只读页面和生成的练习笔记都读这一份，不会两边不一致；
- 它们是**应用自带的文档**，随代码更新，不是个人数据。

速查表的数据（快捷键、语法）放在 `web/src/lib/help.ts`，一条一行：按键或写法、作用、在哪里生效。

- 单测检查表里列的应用级快捷键和 `keyboard.ts` 实际识别的一致：改了快捷键忘了改速查表，测试会失败。

## 四、章节（三块，每章末尾都有「动手试试」）

**写笔记基础**

1. 新建与保存：Ctrl+N、自动保存、Ctrl+S、快速捕获 Ctrl+Shift+Space、收件箱
2. Markdown、双链与标签：`[[标题]]`、`[[` 补全、`#标签`、任务框、Ctrl+B / I / K
3. 分组与子项目：分组、子项目、连读入口、拖 .md 导入到项目
4. 图片：粘贴 / 拖入、`![[图|300]]`
5. 历史版本与回收站：Ctrl+Shift+H、恢复与撤销恢复、回收站保留天数

**模板与 AI**

6. 笔记模板：新建页选模板、子项目默认模板、复制成提示词、专属提示词
7. 按模板规整：粘贴大段后的提示条、只搬不改、撤销
8. AI 生成模板：一句话描述 / 从笔记归纳
9. 右栏 AI 与 AI 对话：Ctrl+J、改稿与整篇替换、AI 计划要先批准

**复习与备份**

10. 知识简卡：`> [!card] 概念`、`概念 :: 解释`、卡片墙、今日复习 Ctrl+Shift+R
11. WebDAV 备份：设置、每日快照、从快照恢复
12. 一键启动与更新：双击启动、`git pull` 后自动重建、旧页面的更新提示

「动手试试」写成可以在练习笔记里直接改的小任务，例如：

- 「把下面这行改成双链：参见 使用手册 / 新建与保存」；
- 「下面这行已经是一张简卡，去卡片墙找它」。

只读页面里也显示这一节，但写明「生成练习笔记后才能动手」。

## 五、界面

**帮助面板**（左栏底部「帮助」按钮 / `?` / Ctrl+K「帮助」）：右侧抽屉，两个页签。

- **速查**：
  - 快捷键分组列出：全局、编辑器、阅览模式、连读、复习；
  - 语法分组列出：双链、标签、任务、简卡、图片、模板提示注释；
  - 顶部一个筛选框，输入字就过滤。
- **使用手册**：
  - 左边章节目录，右边是渲染好的章节（和预览同一套渲染，安全转义规则不变）；
  - 只读；章节里的 `[[双链]]` 指向手册内的另一章时，在面板里跳过去。
  - 底部：
    - 「生成练习笔记」：还没生成时显示；
    - 「重新生成（换成最新版）」「删除练习笔记」：已经生成时显示。

**生成练习笔记**：

- 在「使用手册」分组下建一个子项目「使用手册/练习」，每章一篇，加一篇目录（`type: index`）。
  - 所以在左栏点它就是连读，按目录顺序读。
- 文件头加一行 `manual: <手册版本>`，用来认出哪些是练习笔记。
- 生成后打开连读页，提示「已生成 12 篇练习笔记，可以随便改，练完在帮助里一键删除」。

**重新生成**：

- 先问：「改过的练习笔记会先移进回收站，再生成最新版。」
- 确认后：
  1. 把带 `manual:` 的练习笔记移进回收站；
  2. 生成新版。
- 回收站能找回。

**删除练习笔记**：

- 确认后把带 `manual:` 的练习笔记都移进回收站，并清掉「使用手册/练习」这个空分组。
- 其它笔记一篇不动：即使放在这个组里、但没有 `manual:` 行的，也不动。

## 六、接口

| 接口 | 说明 |
|---|---|
| `GET /api/help/manual` | `{ version, chapters: [{ slug, title, part, body }], installed: { count, version } }` |
| `POST /api/help/manual/install` | 生成练习笔记；已经有了返回 409（前端改走重新生成） |
| `POST /api/help/manual/reinstall` | 旧的移进回收站后重新生成 |
| `DELETE /api/help/manual` | 练习笔记移进回收站 |

写笔记一律经 `store.ts`，删除走现有的回收站（`moveToTrash`），写完进索引，推送通道照常通知其它标签页。

## 七、约束

- Markdown 文件仍是唯一真源：练习笔记就是普通 `.md`。
- 手册内容渲染走 `markdown.ts`，原始 HTML 照旧转义。
- 不新增依赖；颜色只用 token，浅色和深色都检查。
- `?` 只在不在输入框、没有弹窗时生效；带修饰键的组合不接管。

## 八、不在这次范围

- 「阅读与导出」单独成章（用户这次没选；快捷键在速查表里）。
- 交互式引导（高亮按钮一步步带着点）。
- 多语言。

## 九、测试

- **单元测试**：
  - 速查表里的应用级快捷键和 `keyboard.ts` 一致；
  - 速查筛选；
  - 手册文件解析（标题、所属部分、顺序）；
  - `manual:` 识别；
  - 目录笔记内容。
- **接口测试**：
  - 读手册；
  - 生成（文件、子项目、目录、`manual:` 行）；
  - 重复生成返回 409；
  - 重新生成：改过的进了回收站，新版齐全；
  - 删除：只删练习笔记，同组里手写的不动。
- **E2E**：
  - 按 `?` 打开速查，筛选「复习」只剩相关行；
  - 在输入框里按 `?` 不打开；
  - 左栏「帮助」→「使用手册」读一章、点章内链接跳章；
  - 生成练习笔记 → 连读页 12 章 + 提示；
  - 在练习笔记里做一个「动手试试」（改成双链）；
  - 删除练习笔记 → 回收站里有、左栏没了；
  - Ctrl+K「快捷键」找到帮助；
  - 浅色和深色各截一张图。
