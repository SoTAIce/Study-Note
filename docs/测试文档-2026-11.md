# 测试文档（2026-11 新功能）

覆盖 2026-11-13 ~ 2026-11-15 做完的功能。每项按「操作 → 预期」试一遍，通过就把 `[ ]` 改成 `[x]`；不通过在「备注」里写下做了什么、看到了什么。

自动化测试（`./init.sh`：462 个单元 / 接口测试 + 搜索和启动两个基准 + 24 步浏览器测试）已全部通过，并在 GitHub Actions 的 Linux、Windows 上跑过。这份文档是**人在真实电脑上**的验收，重点是自动化测不到的部分（真实剪贴板、输入法、读屏、坚果云）。

## 准备

1. 切到分支 `claude/modest-bardeen-2ldhi4`，执行 `pnpm install`。
2. `pnpm start`，浏览器打开 http://127.0.0.1:7777 。
3. 第一次启动会把索引完整重建一次（笔记多时等几秒），之后启动很快。
