# Study Notes

## 项目简介

Study Notes 是一个面向个人学习记录与想法整理的本地笔记应用。笔记以 Markdown 文件作为唯一数据源，SQLite 仅用于全文检索、标签、双链和时间线索引，因此可以随时使用 VS Code、Typora 或 Obsidian 直接查看和编辑原始笔记。

项目提供 React Web 界面、Node.js 本地服务、全局快捷捕获和可选 AI 辅助能力。应用默认只监听 `127.0.0.1`，个人笔记保存在 `data/notes/`，适合在 Windows 个人电脑上本地部署。

### 界面

- 浅色 / 深色两套主题，默认跟随系统；左栏顶部的图标可在「跟随系统 → 浅色 → 深色」之间切换，选择会被记住。
- 编辑区可在「只写 / 分栏 / 只看预览」三种视图间切换（标题右侧的分段按钮）。
- 阅览模式：工具栏的书本按钮或 `Ctrl+Shift+F`。只读排版，左侧目录可跳转，`←` / `→` 切换上一篇 / 下一篇，记住每篇读到的位置，`Esc` 或 `E` 回到编辑。
- 新建笔记：左栏选中某个分组时新建，分组栏会自动填好这个分组，可以改成别的或清空。
- 回收站：删掉的笔记先进回收站，可恢复；放进去超过 30 天的自动永久删除（启动时和之后每 6 小时检查一次）；回收站页右上角可「清空回收站」，要再确认一次。
- 导出 PDF：工具栏的下载按钮（阅览模式里也有）。默认「手机阅读」版式（100×178mm、大字号，传到手机上不用放大就能读），也可选 A4、深色。PDF 由电脑上已装的 Edge 或 Chrome 在后台生成；都找不到时会打开打印对话框，选「另存为 PDF」即可。浏览器装在非默认位置时，用环境变量 `STUDY_PDF_BROWSER` 指定它的完整路径。
- 历史版本：编辑页工具栏的时钟按钮或 `Ctrl+Shift+H`。打开笔记后的第一次保存、之后每隔 10 分钟、AI 改写前和恢复前都会自动存一份，可预览、逐行对比、一键恢复（恢复本身也能撤销）。较早的版本会自动稀疏（7 天内每小时一份，90 天内每天一份，之后每周一份）。
- 窄窗口（≤760px）下左栏收为抽屉，顶部出现操作栏，手机浏览器也能正常使用。

## 部署方式

### 环境要求

- Windows 10/11
- Node.js 24 或更高版本
- pnpm（推荐）或 npm

### 一键部署

```powershell
git clone https://github.com/SoTAIce/Study-Note.git
cd Study-Note
```

双击根目录的 `启动笔记.bat`。首次启动时，脚本会自动安装依赖、构建前端、启动本地服务并打开浏览器；后续启动会直接复用已安装的依赖和构建结果。

默认访问地址：<http://127.0.0.1:7777>

### 手动部署

```powershell
pnpm install
pnpm build
pnpm start
```

如果没有 pnpm，可将以上命令中的 `pnpm` 替换为 `npm`。

## 开发与协作

本项目按 [Learn Harness Engineering](https://walkinglabs.github.io/learn-harness-engineering/en/) 的方法管理，人和编码代理用同一套流程：

- `AGENTS.md`：入口，写明开工 / 收工流程、完成的定义和硬性约束（`CLAUDE.md` 只是导入它）
- `feature_list.json`：要做什么、做到哪了的唯一来源，每条带验证步骤和证据
- `claude-progress.md`：每个会话的进度日志；`session-handoff.md`：中途交接
- `./init.sh`：标准验证路径（依赖 → 类型检查 → 单元测试 → 构建 → 端到端测试），基线不绿先修基线
- `pnpm e2e`：真浏览器端到端冒烟测试（需要 Playwright），截图在 `e2e-artifacts/`

每次推送和 PR 会在 GitHub Actions 上用 Linux、Windows 各跑一遍完整基线（`./init.sh`），结果在仓库的 Actions 页，失败时可下载截图和导出的 PDF 附件。
